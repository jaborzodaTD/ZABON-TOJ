# ZABON — AI Language Academy 🌍

Founder: **JABORZODA FAYZALI**

This is the **ZABON Global v1 static edition**. It is designed to work directly on GitHub Pages without Node.js, npm, Terminal, PHP or a database.

## Upload
Upload all files/folders in this ZIP to the root of a GitHub repository.

GitHub Pages can publish static HTML/CSS/JavaScript directly from a repository.

## Included
- Premium responsive UI
- 15 languages
- 30-day A1 course structure
- XP, streak and achievements
- Local progress with localStorage
- AI Tutor demo interface
- Translator demo
- Dictionary
- Saved vocabulary
- Daily review
- Challenges
- Profile and settings
- Dark mode
- PWA manifest + service worker
- Founder attribution

## Important
This static edition does **not** fake backend functionality. Google/Telegram/Apple login, real AI models, unrestricted machine translation, cloud sync, payments, server-side speech recognition, admin RBAC and production analytics need a secure backend/API.

## GitHub Pages
1. Create a repository.
2. Upload the contents of this ZIP.
3. Open Settings → Pages.
4. Select the publishing source/branch.
5. Open the generated Pages URL.

GitHub's official Pages documentation: https://docs.github.com/en/pages
